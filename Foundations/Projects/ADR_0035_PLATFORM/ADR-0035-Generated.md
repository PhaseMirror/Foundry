# ADR-35: Global Research Platform

- **Status:** **Accepted (Blocked on Layer B)**
- **Layer B Gated:** Yes (Strict Fail-Closed)

## Context
Proposal to convert Sovereign Core into public research program with credentials.

## Decision
Define platform as future Layer-B-gated capability; remain fail-closed.

## Consequences
- Zero certificates accepted
- Zero tokens minted
- Local verification generates private witnesses only
