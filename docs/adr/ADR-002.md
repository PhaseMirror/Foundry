# ADR-002: Sedona Spine Retention Engine Sole Source of Truth

**Status:** Accepted

## Context
Decentralized litigation hold rules risk spoliation drift if computed independently by UI or client agents.

## Decision
All ESI preservation risk logic must route exclusively through the Sedona Spine Rust Engine and WASM SDK.

## Consequences
* Zero drift in litigation hold calculations
* Mandatory provenance chain: Policy -> Event -> Kernel -> Witness
