# ADR-0023: The δJ7 Principle — Symmetry-Complement Source Sectors in MnF₂

**Status:** Accepted

## Context
Small imbalance between symmetry-distinct J7a/J7b bonds as candidate source coordinate for chiral response. Statement of 'symmetry complement' relative to declared reference must be fixed.

## Decision
Adopt δJ7 principle: group averaging defines projector P; V = im P ⊕ ker P; source sector Vₘ = span{λₘ,ₐ}; δJ7 ≡ J7b − J7a; odd-channel expansion F_-(λ) = k·λ + O(‖λ‖³).

## Consequences
* Source attribution tied to declared reference model
* Odd-channel expansion fixes chiral response scaling
* Mathematical substrate for ADR-0024 and ADR-0025
* Warning against universal weak coordinate export
