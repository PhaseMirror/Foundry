ADR-0027: When Null Does Not Mean Absent — Measurement-Map Geometry

Status: Accepted

Context

A null outcome is not physical absence. Latent state passes through source, response, probe, averaging, transfer, and nuisance stages. Four-null distinction generalized to compositional calculus.

Decision

Adopt layered geometry: M = T ∘ A ∘ P ∘ R ∘ S; null-then-witness filtration K_j = ker F_j; refactor attribution; target-specific closure K_j ⊆ ker C; common-state closure by kernel intersection.

Consequences

  • Every null attributed to specific stage or label withheld
  • Raw signal can be non-identifying; null can coexist with nonzero signal
  • Reversal channels double as obstruction testbeds
