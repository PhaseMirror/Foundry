# ADR-0040: Conscious Sovereignty Layer, Zenolock, and the PIRTM Dialect

**Status:** Proposed

## Context
Introducing a sovereign execution layer (Zenolock) that enforces immutable state transitions for PIRTM programs.

## Decision
Adopt Zenolock as the runtime guard; integrate with the Conscious Sovereignty Layer for auditability.

## Consequences
* End-to-end tamper-evidence
* Deterministic replay
* Reduced attack surface
