# ADR-0061: Strict Validation & Fail-Closed Errors for Missing Delimiters

**Status:** Accepted

## Context
To eliminate ambiguity between header-only packaging files and full application code contracts.

## Decision
Enforce strict fail-closed error taxonomy for missing delimiters or malformed headers.

## Consequences
* Explicit error messages for end-users and client IDE extensions
* Eliminates ambiguous parsing behavior
