# ADR-0035 — Global Research Platform: Production-Grade Lean 4 Implementation

> Machine-checked, Layer-B-gated formal model of **ADR-0035 "Global Research Platform"**
> (Status: *Accepted — blocked on Layer B*), implemented inside the live `Foundations.ADR`
> governance library.

## 1. Executive Summary

ADR-0035 makes the Global Research Platform a **Layer-B-gated, fail-closed** capability: until the
annotated tag `v1.0.0-Stable` exists and its tree SHA is recorded in `CONTRACT.md`, no certificate is
accepted and no token is minted. This document records the production-grade Lean 4 implementation that
encodes that membrane as dependent types and proves the fail-closed guarantee, the frozen MSC-Cert v1
schema, and the preserved invariants — axiom-clean (no `mathlib`, no `sorry`).

## 2. Design Rationale & Formal Model

**Why Lean 4.** ADR-0035 is an Accepted governance record whose central tension is *membrane integrity vs.
community velocity*. The only sound way to guarantee "fail-closed unless Layer B exists" is to make the
gate a **type-level** and **computational** obligation, not a prose promise. Lean 4 provides:

- **Dependent types** for `LayerBIdentity` / `KnownLayerB` (a Σ-witness that can only be constructed when a
  valid, contract-recorded Layer B identity is actually supplied).
- **Computational gates** (`acceptCertificate`, `mintMSC`) that default to the closed branch (`none` /
  `Rejected`), so the only reachable open state requires an existentially-present, recorded Layer B.
- **Embedded propositional logic** (`PropTerm` / `Entrails` from `Core.lean`) for semantic conflict detection
  between accepted claims.

**Core definitions (in `Foundations/ADR/GlobalResearchPlatform.lean`):**

| Symbol | Kind | Meaning |
| :--- | :--- | :--- |
| `LayerBIdentity` | `structure` | `tag`, `treeSHA`, `recordedInContract : Bool` (Article III identifier) |
| `LayerBValid b` | `Prop` | `b.tag = "v1.0.0-Stable" ∧ b.recordedInContract = true` |
| `KnownLayerB` | `structure` | `{ id : LayerBIdentity, valid : LayerBValid id }` — exists only when Layer B is valid |
| `MembraneState` | `inductive` | `FailClosed` \| `Operational` |
| `membraneState kb` | `def` | `Operational` iff `kb : Option KnownLayerB` is `some` |
| `MSCCert` | `structure` | Frozen MSC-Cert v1 schema (version, keys, `git_commit`, env, `release_witness`, hashes) |
| `MSCCertValidAgainst cert b` | `Bool` | `git_commit = b.treeSHA ∧ release_witness.merkle_root = b.treeSHA` (+ recorded tag) |
| `MSCCertAccepted cert g` | `Prop` | `∃ b ∈ g, MSCCertValidAgainst cert b = true` |
| `acceptCertificate cert g` | `Option MSCCert` | `some cert` only if a recorded Layer B validates it; else `none` |
| `mintMSC cert g` | `MintReceipt` | `Minted` only if accepted; else `Rejected "LayerB-gate-fail-closed"` |
| `PreservedInvariant` | `inductive` | The 7 membrane invariants ADR-0035 must not weaken |

**Key theorems (all proved, no `sorry`):**

- `accept_certificate_fail_closed` — with `globalLayerB = none`, acceptance is unconditionally `none`.
- `accept_certificate_some_iff_valid` / `accept_iff_accepted` — acceptance characterisation over the global state.
- `acceptCertificate_cases` — acceptance yields only `none` or `some cert` (never another value).
- `mint_fail_closed` — with no Layer B, minting is always `Rejected`.
- `mint_rejected_unless_accepted` — a non-accepted certificate can never mint.
- `grp_preserves_all_invariants` / `grp_leaves_feMoco_freeze_intact` — the membrane invariants, including the
  FeMoco 69-qudit `Production_Mode_Lock` envelope, are preserved.
- `grp_membrane_independent_of_feMoco` — membrane posture depends solely on Layer B, not on the qudit envelope.

## 5. Core Modules

### `Foundations/ADR/GlobalResearchPlatform.lean` (new)

- **Purpose.** Encodes ADR-0035's binding choices as machine-checked types and proves the membrane is
  fail-closed until Layer B exists.
- **`LayerBIdentity` / `KnownLayerB`.** A value of `KnownLayerB` is a `Σ`-witness `(id, valid)`; because
  `LayerBValid` requires the recorded `v1.0.0-Stable` tag, such a value *cannot* be constructed while the
  gate is closed. This makes "no valid Layer B ⇒ no open membrane" a property of the type system.
- **`MSCCert` (frozen schema).** Mirrors ADR-0035 §Frozen Schema Reference: `certificate_version`,
  `builder_public_key`, `git_commit`, `environment`, `release_witness` (`merkle_root`, `leaves`),
  `test_logs_hash`, `timestamp_iso`, `signature`.
- **`acceptCertificate` / `mintMSC`.** Computational gates; the `none` / `Rejected` branch is the default and
  the only reachable outcome when `globalLayerB = none`.
- **Theorems cited in §2** are all discharged with `simp` / `by_cases` / `decide` — no axioms, no `sorry`.

### `Foundations/ADR/Examples.lean` (extended)

- `adr0035`, `adr008zk`, `adr009msc` — the ADR-0035 record and its two governing related artifacts, each
  `status := .Accepted`, with traceability `links` into `CONTRACT.md`, `Production_Mode_Lock.md`, and
  `Foundations.ADR.GlobalResearchPlatform`.
- `grpADRList` / `grpRegistry : ADRRegistry` — a verified 3-ADR slice discharging `uniqueIds`, `acyclic`,
  `supersedesExist`, `supersededStatusConsistent`, `noConflicts`, `claimsOwnedByAccepted`, `noClaimConflicts`.
- `sampleMSCCert` + `sample_cert_rejected_today` / `sample_mint_rejected_today` /
  `sample_cert_rejected_against_mismatched_layerB` — concrete proofs that today's membrane rejects any
  submission and any token, even against a fake `v1.0.0-Stable` whose tree SHA mismatches.

### `Foundations/ADR/Export.lean` (extended)

- `grpPosture`, `grpGovernanceReport`, `exportGRP` — render the membrane posture, Layer-B gate status, and
  the verified ADR slice as timestamp-free Markdown (byte-stable for CI `git diff --exit-code`).

### `Foundations/ADR/Test.lean` (extended)

## 7. Usage Guide (write + prove a new gated ADR)

1. `lake new` (or, in this repo, open `Foundations/ADR/`).
2. Add a record in `Examples.lean`: `def adrNNNN : ADR where id := "ADR-NNNN", status := .Accepted, ...`.
3. If it gates on Layer B, assert `MSCCertAccepted cert globalLayerB` before any `acceptCertificate`/`mintMSC`
   call; the type system forces you to supply a recorded `KnownLayerB`.
4. Add it to a registry list and discharge the `ADRRegistry` fields (use `decide` for `uniqueIds`/`noConflicts`,
   `by` for `acyclic`, `simp` for claim satisfaction).
5. Add a `#check` in `Test.lean` and a property/negative test; run `lake test`.

To **re-open** the path (future ADR under an existing Layer B): construct `KnownLayerB` from a recorded
`v1.0.0-Stable` identity and supply it as `globalLayerB`; `acceptCertificate`/`mintMSC` then become reachable,
and the proofs above guarantee the opened state is exactly the contract-recorded tree SHA.

## 8. Production Hardening

- **CI/CD.** Gate merges on `lake test` (exit 0) and on `git diff --exit-code docs/adr docs/adr/grp` (the
  generators are timestamp-free, so exported bytes are deterministic).
- **Documentation generation.** `exportGRP none grpRegistry "docs/adr/grp"` runs inside `lake test`; the
  GOVERNANCE report is regenerated on every suite run.
- **Extensibility.** `PreservedInvariant` is an open `inductive`; add a constructor + discharge
  `grp_preserves_all_invariants` (a single `cases i <;> decide`). The frozen MSC-Cert schema is intentionally
  a `structure`, not an embedded DSL — replace with a richer codec without touching the gate proofs.
- **Common pitfalls + mitigations.**
  - *Pitfall:* claiming stability before Layer B → `acceptCertificate cert none = none` makes any such claim
    unprovable. *Mitigation:* the type system rejects it.
  - *Pitfall:* a fake `v1.0.0-Stable` with a wrong tree SHA → `MSCCertValidAgainst` requires `git_commit`
    **and** `merkle_root` to equal the recorded `treeSHA`, so mismatches are rejected (`sample_cert_rejected_against_mismatched_layerB`).
  - *Pitfall:* `sorry`/`mathlib` creep → ADR-0035 forbids both; CI lints for `sorry` (see `alp_sorry_manifest.json`)
    and the ADR modules import no `mathlib`.
