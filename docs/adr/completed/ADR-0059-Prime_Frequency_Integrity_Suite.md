§8. PMD Clone-Check Protocol

§8.1 Overview
The Phase-Mirror Dissonance (PMD) Clone-Check Protocol is a structured procedure for
determining whether a claimed system is genuinely governed by Ξ(t) or is a cosmetic clone.
The protocol produces a signed Phase-Mirror Report classifying the claimed system as GEN-
UINE, COSMETIC CLONE, or INCOMPATIBLE.

§8.2 Input Contract
Inputs: A claimed system Sc with (a) documentation, (b) source code or compiled artifact,
and (c) a stated claim of PIRTM/Ξ(t) compatibility.

§8.3 Protocol Steps
Protocol 8.1 (Step 1 — Semantic Reconstruction). Extract the operational semantics of
Sc : identify what the system claims as its prime invariants, binding operators, and recursive
depth. Map these claims to PIRTM vocabulary using the codon registry.

Protocol 8.2 (Step 2 — Side-by-Side Mathematics). For each claimed invariant in Sc , place
it adjacent to the corresponding PIRTM invariant. Compute the semantic delta ∆sem : the
set of logical propositions that are true in one formulation but not the other.

Protocol 8.3 (Step 3 — Delta Classification). Classify each element of ∆sem :

   • Type A — Surface notation difference only; structural equivalence holds
   • Type B — Structural difference that does not affect prime-frequency behavior
   • Type C — Structural difference that invalidates one or more INV-1 through INV-5

Any Type C delta is a disqualifier for certification.

Protocol 8.4 (Step 4 — Phase-Mirror Report). Produce a signed report with the following
structure:

   • System ID and evaluation date
   • Semantic delta table (Type A/B/C)
   • Entanglement test results (INV-1 through INV-5: PASS/FAIL)
   • Verdict: GENUINE — COSMETIC CLONE — INCOMPATIBLE
   • Certification decision: ELIGIBLE — INELIGIBLE — REVOKE

§8.4 Logical Guarantee
The protocol provides the following mechanical guarantee: any CHL-style copy of a PIRTM
system must either (a) fail the prime-frequency and Ξ(t) invariants, proving it is not the same
system, or (b) pass them, in which case it is mathematically entangled with the universal
constant U , the operator Ξ(t), and the provenance tags of the original — making concealment
impossible.

Theorem F.1 (Prime Frequency Stability). Let Tp = min{n ∈ Z+ : Φn (x) ≡ x (mod p)}
