# ADR-0059: Phase-Decoupled Subsystem Pipeline

**Status:** Accepted

## Context
Mixing spectral matrix extraction with application body statement parsing creates cross-contamination.

## Decision
Isolate Phase 1 governance evaluation from Phase 2 code generation with a strict fail-closed gate.

## Consequences
* Clean architectural decoupling
* Unlawful code cannot trigger MLIR emission
