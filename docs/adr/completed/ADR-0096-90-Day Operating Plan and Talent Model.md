# ADR-0017: Reinitialization — 90-Day Operating Plan and Volunteer Talent Model

**Status:** Completed

## Context
The UOR Foundation must reinitialize under a volunteer-led, no-funding assumption. The organization cannot outrun its operating structure, so the next unit of value is confidence: a bounded thirteen-week cycle that produces a governed, independently verifiable value-layer baseline under strict WIP and ownership controls.

## Decision
Adopt the 90-Day Operating Plan and Volunteer Talent Model as the bounded execution system for the reinitialization cycle.

- **One primary objective.** A governed, independently verifiable value-layer baseline. No secondary objectives dilute it.
- **Day Zero: two-week mobilization.** Before execution starts, six conditions must be ownerless-proofed: defined authority, clear scope, published public facts, volunteer capacity, release custody, and named stewardship. Exit rule: if any of the six conditions remains ownerless or materially ambiguous, do not start Week 1 — continue maintenance and governance preparation.
- **Five workstreams, maximum.** W1 Authority and public truth; W2 Core Value Profile; W3 Conformance and release; W4 Explanation and participation; W5 External validation. Adding a sixth requires an amendment.
- **Thirteen-week map.** Each week has a named deliverable and owner; the cycle closes with end-of-cycle deliverables including the Core Value Profile v0.1, a canonical conformance corpus, a coordinated baseline release, a public explanation, and one evaluated external path, plus the release-candidate dossier.
- **Accountability model.** Every workstream has explicit roles and a RACI; no abstract responsibilities.
- **Volunteer talent model.** Participation runs in defined lanes and modes; each volunteer's contribution packet is recorded so negative evidence counts as evidence.
- **Work board controls.** Tasks move through stated workflow states under WIP limits; every task carries owner + reviewer + timebox + definition of done. Metrics are enforced: 100% conformance across canonical surfaces, 100% of assessed assets, 100% agreement on reference + independent evaluations.
- **Action register.** Decisions are logged as actions (A01–A26+) with ID, owner, and gate; nothing proceeds without a registered action item.

## Consequences
* Execution is capped by WIP limits, so scope cannot expand silently mid-cycle.
* No-funding assumption is binding; volunteer capacity is treated as a planning envelope, not a labor valuation.
* The cycle either closes its deliverables or fails its exit rule loudly; there is no zombie state.
* Decision cadence (weekly/biweekly/monthly) is fixed up front and recorded.
