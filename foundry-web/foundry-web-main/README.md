# Foundry Web

The UOR Foundation's portal at `https://app.uor.foundation`, to be defined
with PrismPM and prism-stdlib. The Foundation is dedicated to the
democratization of technology for the well-being of humanity and operates
under the Citizen Gardens model through a network of Foundries. The first
Foundry is also the Foundation's headquarters.

## Status

Repository bootstrap only, created from
[UOR template](https://github.com/UOR-Foundation/template/tree/e0e11ecb1b38e202116d9806887363848629d439).
No application capability or production deployment is accepted yet.
The required scope is in [SPEC.md](SPEC.md); remaining work is tracked in
[IMPLEMENTATION.md](IMPLEMENTATION.md).

The inherited `prismpm.lock` and `template.lock` are absent. The devcontainer
and complete `just vv` gate require an accepted immutable SDK release;
source checkouts and host tools are not substitutes.

The conformance registers remain empty until modeled capabilities have
their required scenarios, implementation, and verification evidence.
Repository policy is in [AGENTS.md](AGENTS.md) and
[TEMPLATE-CONTRACT.md](TEMPLATE-CONTRACT.md).
