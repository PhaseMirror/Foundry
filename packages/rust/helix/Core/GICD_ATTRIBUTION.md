# GICD Framework Attribution

## Independent Derivation, Partial Convergence

The HELIX-CORE implementation of GICD (Governance Integrity and Constitutional Defense)
was independently derived as a pre-nucleation gate for constitutional AI governance.

The original GICD framework was created by **Samantha L. King**, Founder & CEO of
King Insights Group. Her framework operates through six integrated pillars:

| Pillar | Function |
|---|---|
| 1. Structural Mapping | Identifies where systems fail, not just that they failed |
| 2. Behavioral Diagnostics | Maps the human reality inside the system |
| 3. Communications Forensics | Analyzes metadata, message patterns, and information failures |
| 4. Retaliation Pattern Analysis | Interprets retaliation as data — earliest warning of governance collapse |
| 5. Ethics Drift Detection | Detects long-term normalization of deviance before it becomes visible |
| 6. Governance Remediation & Stabilization | Prescriptive pillar: fix, rebuild, prevent recurrence |

## HELIX-CORE Mapping

Our implementation maps to elements of **Pillar 1** (Structural Mapping) and
**Pillar 5** (Ethics Drift Detection):

- **Pillar 1 → GICD Scanner**: Four boolean/semantic markers (authority ambiguity,
  incentive misalignment, cost externalization, governance capture) that identify
  structural failure points before agent nucleation.
- **Pillar 5 → Drift Detection**: The δ_crit = 0.17 threshold, ZTC harness, and
  constitutional compliance checker detect normalization of deviance in AI outputs.

Pillars 2, 3, 4, and 6 are not currently implemented in HELIX-CORE.
